# Playlist to MP3

A free Windows app that saves YouTube playlists and videos as **MP3 files** in a folder you choose. It works in the background like OneDrive or Google Drive, and continues by itself after a restart, an internet drop, or when YouTube asks it to slow down.

## Features

- Search YouTube for **playlists or videos** and press **Add** to put them in a download list.
- Paste **one or many links** at once, or add **your own playlists** after signing in.
- Files are named after the video, for example `Song title.mp3`. Quality is 128–320 kbps, 192 by default.
- Optional **subfolder per playlist**.
- Shows progress such as **"208 of 1249 done"**, the status of each song, and **Retry failed**.
- **Start, Pause/Resume, Stop**, plus **Clear list** and a remove button for each item.
- Runs in the **taskbar tray**. Double-click the icon to see progress.
- **Starts with Windows** and continues where it left off.
- Waits for the internet to come back, and handles YouTube "slow down" messages with a countdown and **Try now**.
- Checks playlists **every hour for new videos** and never downloads the same song twice.
- **YouTube sign-in** through Firefox, or a cookies.txt file from Edge or Chrome.
- Dark theme with red accents.
